# The Brainrot

Static site, no build step.

Run: `python3 -m http.server 8000` then open http://localhost:8000
Deploy: drag this folder to Netlify Drop / Vercel / GitHub Pages (HTTPS needed for Share and clipboard).

Edit characters, natures, jokes, slang, roasts and ranks in `data.js`.

Easter egg: Konami code or tap the logo 5 times.
